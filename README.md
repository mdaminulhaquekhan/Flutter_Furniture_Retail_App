# 🪑 Flutter Furniture Retail App

> A modern cross-platform furniture retail application built with Flutter and Dart.

## 📌 Overview

Flutter Furniture Retail App is a cross-platform mobile and web application designed to provide users with a convenient furniture shopping experience.

The application is built using Flutter and Dart and integrates Firebase services for authentication and cloud-based data management.

It provides a modern and responsive interface for browsing furniture products and managing the overall shopping experience.

## ✨ Features

- 🪑 Browse furniture products
- 🔍 Explore product details
- 👤 User authentication
- 🔐 Secure login and registration
- ☁️ Firebase integration
- 📦 Product data management
- 🎨 Modern Material 3 interface
- 📱 Cross-platform support
- ⚡ Responsive user interface
- 🛍️ Furniture retail experience

## 🧰 Technologies Used

- Flutter
- Dart
- Firebase Core
- Firebase Authentication
- Cloud Firestore
- Material 3

## 🌐 Supported Platforms

The application can be developed and deployed for multiple platforms:

- Android
- iOS
- Web
- Windows
- macOS
- Linux
